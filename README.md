# Visual Research Hub — public information site

Prepared as standalone static files for deployment in a **separate public GitHub Pages repository**. This folder in the production repository is only a staging copy. **Do not make the production repository public.**

## Deployment
1. Create a new **public** repository (suggested name: visual-research-hub-site).
2. Copy index.html, privacy.html and styles.css to its root.
3. In the new repository Settings → Pages, select Deploy from a branch, main, / (root), and Save.
4. Open both deployed URLs and verify they load before submitting to Pinterest.
5. Use Pages root as Company website or App link, and /privacy.html as Privacy policy.

No credentials should ever be added. This site documents **planned** functionality and is not a claim that Pinterest API access has been approved. Review policy text for accuracy against the final implementation before publishing. GitHub connector in this session does not expose repository creation or Pages configuration.
